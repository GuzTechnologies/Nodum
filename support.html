Ayuda

Soporte de Nodum

Estamos para ayudarte a configurar una pausa que funcione.

Configuración inicial

  1. Elegí las aplicaciones que querés administrar desde Límites.
  2. Activá Acceso al uso para que Nodum pueda medir únicamente su tiempo en primer plano.
  3. Activá Mostrar sobre otras apps para ver el aviso o bloqueo al alcanzar el límite.
  4. Permití las notificaciones para recibir el aviso alternativo y ver el estado del monitoreo.

Si el bloqueo no aparece

  • Confirmá que Nodum tenga Acceso al uso y permiso para mostrarse sobre otras aplicaciones.
  • Revisá que la aplicación esté seleccionada, el interruptor de bloqueo esté activo y la franja horaria incluya la hora actual.
  • En fabricantes con ahorro de batería agresivo, excluí Nodum de la optimización de batería.
  • Volvé a abrir Nodum después de reiniciar el teléfono para comprobar el estado de los permisos.

Nodum depende de permisos y servicios proporcionados por Android. Si un permiso se revoca o el sistema detiene el servicio, el aviso o bloqueo puede demorarse o no mostrarse.

PIN

El PIN tiene cuatro dígitos y permite habilitar accesos temporales. Guztech no recibe ni puede recuperar el PIN porque su derivación se guarda únicamente en el dispositivo. Si lo olvidás, podés borrar los datos de Nodum o reinstalar la aplicación; esto también elimina la configuración y estadísticas locales.
